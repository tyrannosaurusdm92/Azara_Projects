QUICK GUIDE

Use the glyph workshop

  1. Choose an era. Each era has its own inventory and artwork. Add one Unicode character at a time, remove rows, or edit multiple phonetic fields in Era inventories.
  2. Draw or upload. Select a character, draw in the square, upload an image, or drag files onto the glyph grid. Use layers, transforms, brush tools, and undo to refine its shape.
  3. Set its identity and metrics. Edit IPA, meaning, sound family, transliteration, and notes. Adjust the glyph's size, baseline, spacing, and advance width; use Spacing preview for line-wide settings.
  4. Print, fill, and scan. Export a sheet for the active era, fill each labeled box, then scan the full page. Its QR code carries the character and era mapping.
  5. Trace and export. Trace artwork to editable outline data, then export TrueType or OpenType fonts for each era. Use the lineage, marks, and language evolution views to refine the script data.
  6. Save a portable draft. Export project downloads a JSON file with artwork, layer data, metrics, and all six era inventories.

For automatic sheet import, include the whole page and keep it fairly straight. Manual image upload is available whenever a scan cannot be mapped.

Your keyboard

  • One bubble, two languages: Open the 150 × 150 movable keyboard and choose QWERTY or AZA’RAAN in its first dropdown, directly before emoji.
  • Aza’raan: Choose Archaic, Classical, Traditional or Modern in the second dropdown. Tap any sound-first letter to type Khmer-encoded Aza’raan, or hold it for sound variants and up to three stacked accents. There is no X key; X is K + S.
  • Speech: Highlight any Aza’raan letter, word or phrase in the note and tap 🔊. If nothing is selected, the word at the caret (or the note) is used. ⚙️ opens voice depth, speaking speed, volume, and installed voice choices; these change delivery, not accent meanings.
  • Evolution: The second page contains the original full six-stage interactive letter history and source glyph artwork.
  • Keyboard: Right-click or hold for alternatives. Keys cannot be removed, restored, imported or exported. 123 still opens the numbers and symbols pages.
  • Emoji: Search native Unicode emoji, with an external reference link to Emojipedia.
  • Move, resize and close: Drag the title/grip to move, edges/corners to resize, ❌ to collapse back to the bubble. PrtSc captures the visible app as PNG.
