Your writing saves on this device. Install the app separately on each device, then connect the same account: sync this device’s local library to cloud, and restore that snapshot on the other device. Local autosave and downloadable backups remain available.

Account connection

To use this library on another device, connect the same account on both devices. On the current device choose “Sync local → cloud”; on the other choose “Restore cloud → local”. Each upload creates a new cloud snapshot and does not delete earlier copies. Restore replaces that device’s local library after confirmation.
