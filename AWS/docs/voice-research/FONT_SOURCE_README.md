# Original four Aza’raan font files

To restore the original era-specific typography, copy the four **original** TTFs from your own uploaded Azaaraan_Unified_Language_Studio ZIP into this directory:

- Azaaraan-Archaic.ttf
- Azaaraan-Classical.ttf
- Azaaraan-Traditional.ttf
- Azaaraan-Modern.ttf

The browser will fall back to a locally installed Khmer font if these are absent. No replacement font files have been added or modified.
