PURPOSE AND READING RULES
• This is a mapping of the AUTHOR’S AZA’RAAN ENCODING, not a claim that real Khmer
  characters historically evolved from Egyptian hieroglyphs. The Khmer code points
  act as encoding slots for custom Aza’raan artwork and composition.
• Current encoding source: uploaded ZIP, especially json/khmer-canonical.json,
  json/unicode-map.json and assets/ttf/Azaaraan_Modern_20_Letter_Compiled_Proof.ttf.
• Origin source: the 22 author-specified sound-to-hieroglyph correspondences,
  cross-checked against the existing public AWS “Language Evolution Breakdown”
  (AWS/index.html) without making any GitHub edits.
• Phonetic/merger source: uploaded Modern_Azaraan_Letter_Families_Voiced_
  Glide_Revised_2026-11-15(6).txt and the ZIP’s canonical working specification.
• THIS ZIP is authoritative for Khmer code points. The existing website includes
  some older, different Khmer Unicode allocations; a matching glyph/sound NAME
  alone is not sufficient to transfer that older code point to this ZIP.
• Exactly 114 distinct Khmer-block Unicode scalars (U+1780–U+17FF) appear
  literally in readable ZIP files and are covered once each below.
  Of these, 55 are CURRENTLY ASSIGNED by the ZIP: 20 independent letters,
  12 ordinary diacritics, 4 special controls, 10 digits, 8 punctuation signs,
  and 1 COENG joiner. The 55 also exactly match Khmer Unicode scalars in the
  ZIP’s compiled modern proof TTF. The other 59 are CATALOG-ONLY CHARACTERS.
• “UNRESOLVED” means that the supplied origin table does not establish a
  defensible Egyptian ancestor for that character; it does not mean it
  has an Egyptian origin that simply has not yet been discovered.
• Subscripts are sequences U+17D2 (COENG) + the base letter. They are NOT new
  independent Unicode scalars. A supplementary section lists all 20 exact
  two-scalar sequences so future programs can reconstruct them accurately.
• Private-use Aza’raan code points and ASCII/Latin marks in the ZIP are not
  Khmer Unicode characters and are outside this character-specific inventory.

HISTORICAL MERGER SUMMARY
• 𓃚 (old independent Uh /ʌ/) → 𓄣 (A /æ/) AFTER Traditional, BEFORE Modern.
  A now hosts /ʌ/ with Central Vowel; no Modern independent U exists.
• 𓈌 was the V ancestral root chosen for the merged B/V/F glyph. In Modern
  spelling B is the independent host; V = B + Soft; F = B + Soft + Unvoiced.
  Independent P always remains separate.
• Both < (previous syllable) and > (next syllable) emphasis marks trace to
  the SAME root 𓃪, shared with the glottal-stop lineage in the chart.
• Click originates from 𓐎. Neither click nor glottal is an independent
  Modern letter; both function as above-letter special controls.

UNICODE CODE POINT: U+17A2
ORIGINAL EGYPTIAN HIEROGLYPH: 𓄣
