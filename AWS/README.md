# Aza’raan Writing Studio (AWS)

This directory is a **view-only archive**, pending integration of an entirely new input system.

- All previous on-screen keyboards, floating input controls, key buttons, text-entry widgets and editing runtimes have been removed from the active AWS project.
- All previous voice, speech synthesis, microphone/pronunciation practice, typing/phonetic composer and audio cue runtimes have been removed.
- The eight book workspaces may display manuscripts already saved in the device's old LiteraryFriend browser storage, without changing their content.
- The original six-stage language evolution artwork, font files, history data, brand image, manifest and public backend configuration remain in AWS.
- This release does not install any new input system or contact the backend.

Open `index.html` over HTTPS (such as GitHub Pages). The updated service worker deletes old AWS offline caches when it activates. Refresh an older installed app if needed.

No folders outside `AWS/` were edited by this removal.

See [REMOVAL_AUDIT.md](REMOVAL_AUDIT.md).
