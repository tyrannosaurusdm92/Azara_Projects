# Elarvess living map and Aza’raan calendar

The active settlement uses a **21-hour day**, **6-day week**, **5-week month** and **8-month 240-day year**. Every character has six continuously timed daily routines. The map PNG and polygon geometry are unchanged; GeoJSON display names and embedded JS path names were replaced with canonical names. See `ELARVESS_CANONICAL_RENAMES_V4.md`.
