Belavadós Living SVG Settlement Template — Merged Version

Open Belavados_Living_SVG_Settlement_Template_MERGED.html in a browser.

Included merged features:
- Main Image / SVG page for uploaded SVG, HTML, image, PDF/JSON reference files.
- SVG parsing that reads embedded GeoJSON/features, data-name/data-location labels, clickable elements, titles, shapes, pins, anchors, and labeled groups where available.
- Generate from Active SVG uses the exact number of parsed SVG location records.
- Sims 3/4-style NPC detail: traits, aspirations, flaws, needs, moodlets, schedules, households, family trees, relationship layers, jobs, homes, workplaces, visitors, personal inventory, wealth, reputation, secrets, memories, skills, and alignment.
- Internal NPC Directory page with full searchable NPC cards.
- Internal Location Info + Item Search page where searches like breakfast, armor, room, dagger, potion, etc. return locations with full inventory, employees, residents, and visitors.
- Four-axis alignment tracking and alignment JSON import/export.
- Live time and Belavadós calendar/activity tracking.
- Export JSON, NPC CSV, HTML, and ZIP from inside the template. ZIP export is implemented offline with a built-in store-only ZIP writer.

Notes:
- Browser data save uses localStorage.
- SVG files are displayed intact; the parser reads labels/locations without deleting pins, anchors, or polygons.
- For maps with no embedded location labels, use normal generation or add SVG data-name/data-location/title labels.
